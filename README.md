# React GraphQL Framer Motion Example

This is an example project that demonstrates how to use React, TypeScript, GraphQL, and Framer Motion to create a simple application with micro animations.

## Getting Started

1. Clone the repository: `git clone https://github.com/amarg26/anime-app.git`
2. Install dependencies: `npm install`
3. Start the GraphQL server: `ts-node server.ts`
4. Start the React development server: `npm start`

## Features

- React application with TypeScript
- GraphQL schema and resolvers
- Framer Motion for micro animations
